# docs/

Exactly three kinds of content live here, nothing else:

- Example configuration: sample `config.toml`/environment-variable files demonstrating the specification's "Configuration" and "Update Policy" sections.
- Generated `man` pages for the `updater-cli` subcommands.
- `cargo doc` output or its source comments.

This is not the specification and not this project's decisions log; both are maintained in the vault (`CLAUDE.local.md` has the exact locations).
