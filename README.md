# updater

A Rust workspace implementing a secure, cross-platform, versioned release-set installer, launcher, and self-update mechanism for a multi-executable Rust product.

The authoritative specification lives outside this repository. See [`AGENTS.md`](AGENTS.md) and [`CLAUDE.md`](CLAUDE.md) for the engineering contract every change in this repository follows, and `CLAUDE.local.md` (not checked in) for the exact vault location.

## Layout

- `crates/updater-core`: manifest, release, and state types; validated paths; error types; the atomic-write and activation-port traits. No dependency on any other crate in this workspace.
- `crates/updater-launcher`: resolves the active release set and starts a command's executable from it.
- `crates/updater-engine`: the update transaction: manifest retrieval, verification, download, extraction, validation, promotion, activation, rollback, cleanup, and locking, and stable launchers: placing them on `PATH`, keeping them current, and removing them.
- `crates/updater-cli`: the `update`/`rollback`/`install`/`update diagnostics` subcommands, plus a thin `updater` binary for direct use and manual/integration testing.
- `docs/`: example configuration, man pages, and auto-generated Rustdoc; neither the specification nor the decisions log lives here.

## Development

```sh
just ci                 # completion gate: fmt, clippy, test, audit, licences-check, shellcheck
.claude/scripts/check.sh # the same gate, plus repository guidance checks
just licences           # regenerate THIRD_PARTY_LICENSES.md after a dependency change
```

Third-party licence attribution is generated by [`cargo-about`](https://github.com/EmbarkStudios/cargo-about) (`cargo install cargo-about --locked`) from [`about.toml`](about.toml) and [`about.hbs`](about.hbs). `about.toml` lists the accepted licences and the target platforms; `just ci` fails if a dependency uses an unaccepted licence or the committed file is stale.

See [`.claude/README.md`](.claude/README.md) for how the `.claude/` operating handbook is organised.
